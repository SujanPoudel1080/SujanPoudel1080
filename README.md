- **Engineered with**: Go, POSIX PTYs, Unix Domain Sockets, Termios, Kitty Protocol Virtualization
- **Install via Homebrew**:
  ```bash
  brew tap SujanPoudel1080/tap
  brew install dajimux
  ```
- **Install via One-Line Script**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/SujanPoudel1080/dajimux/main/install.sh | bash
  ```
- **Platforms**: macOS (Apple Silicon & Intel) and Linux (`amd64`, `arm64`) with prebuilt `.deb`, `.rpm`, and static binaries.
